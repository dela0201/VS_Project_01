# BC CourseFinder 

BC CourseFinder is an AI-powered career guidance web application designed to help prospective students explore Information Technology (IT) study opportunities at Belgium Campus iTversity.

The platform assists users in discovering suitable IT career paths, understanding programme requirements, comparing qualifications, and making informed study decisions.

## Features

- AI-powered career guidance assistant
- Information on Belgium Campus programmes
- IT career path recommendations
- APS score guidance and eligibility support
- Programme comparison tools
- Career and qualification exploration
- Responsive and user-friendly interface

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### APIs
- AI-powered chatbot integration
